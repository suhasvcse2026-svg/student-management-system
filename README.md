# Student Management System

## Project Description
A simple Python program to manage student records from the command line.

## Technologies Used
Python 3

## Features
- Add student details
- View all student records
- Search for a student by roll number
- Delete a record

## How to Run
1. Install Python 3
2. Download `student_manager.py`
3. Run: `python student_manager.py`

## What I Learned
Python dictionaries, loops, user input handling, and organizing a project on GitHub.
